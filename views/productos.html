SERVICIOS

Spa (60€)

En nuestro circuito de spa podrás disfrutar de un recorrido completo de bienestar, diseñado para relajar el cuerpo y renovar energías.
Contamos con un circuito de calor y frío que combina diferentes temperaturas para favorecer la relajación, una zona de piedras que proporciona una agradable sensación de descanso y chorros de agua a presión que ayudan a aliviar la tensión muscular. Cada espacio está pensado para ofrecer desconexión, tranquilidad y bienestar, cuidando cada detalle para que disfrutes al máximo de tu visita.

Masaje descontracturante (30€)

Los masajes descontracturantes comienzan identificando las zonas con mayor tensión muscular. A continuación, se aplican movimientos y presiones específicas para relajar la musculatura y aliviar las contracturas. Finalmente, se termina con maniobras suaves para favorecer la relajación y proporcionar una sensación de bienestar.

Piedras calientes (20€)

Combina el masaje manual con la aplicación de piedras de basalto a una temperatura específica para transmitir calor profundo y calmar el dolor.

Aromaterapia (20€)

Aplica aceites esenciales (como lavanda o romero) junto con maniobras suaves para potenciar la relajación física y mental.

Exfoliación o masaje con sal (50€)

Mezcla cristales de sal (como sal marina o del Himalaya, a veces con aceites esenciales) para arrastrar células muertas, activar la circulación y dejar la piel suave.
